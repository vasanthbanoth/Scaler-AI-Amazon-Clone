# 🤖 AI-Powered BDD Automation Dashboard

**A next-generation testing tool that converts plain English requirements into automated test executions.**

---

### 🚀 What is this?
[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://share.streamlit.io/)

This application demonstrates the power of **GenAI + BDD** (Behavior-Driven Development).
1.  **You Provide**: A business requirement (e.g., "Login page should verify credentials").
2.  **AI Generates**: A structured Gherkin scenario (`Given-When-Then`).
3.  **System Executes**: Playwright runs the test automatically in a browser.

---

### ⚡ Quick Start

**1. Install**
```bash
pip install -r requirements.txt
playwright install
```

**2. Run**
```bash
streamlit run dashboard.py
```
