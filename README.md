# NTT DATA - Demo Task

This repository contains the code for the AI-Driven BDD Functional Testing demo.

## 📂 Project Location

The main project code is located in the **[NTT_Task](./NTT_Task)** directory.

## 🚀 How to Run Locally

1. **Navigate to the project folder:**
   ```bash
   cd NTT_Task
   ```

2. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   playwright install
   ```

3. **Run the Application:**
   ```bash
   streamlit run dashboard.py
   ```

## ☁️ Deployment Note
This application simulates a deployment on Vercel by serving a static notice (`index.html`). 
For the full functional application (Streamlit + Playwright), please run locally or deploy to Streamlit Community Cloud.
